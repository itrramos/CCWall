# Screenshots

Drop PNG files with these exact names into this folder and they will render in the main
[README](../../README.md).

| Filename | What to capture |
|---|---|
| `dashboard.png` | **Dashboard** — stat cards, wallboard preview panel and recent activity |
| `player.png` | **Live wallboard** at `/display/<slug>` — full screen, ideally an Announcement or Metrics slide |
| `slide-editor.png` | **Slides → edit a slide** — options on the left, live preview on the right |
| `wallboard-editor.png` | **Wallboards → edit a wallboard** — playback settings and the drag-and-drop playlist |
| `media-library.png` | **Media Library** — the thumbnail grid |
| `audit-logs.png` | **Administration → Audit Logs** (or Security/System — update the caption in the README if you swap it) |

## Tips for good screenshots

- Use a **1600×900** or larger browser window; GitHub scales images down, so bigger is sharper.
- Capture the **dark theme** (the default) for consistency — the README tables place shots side by side.
- Blur or replace anything confidential: real names, customer figures, internal hostnames and
  URLs, and especially wallboard **token links**.
- Full-screen the player (press `F`) before capturing `player.png` so no browser chrome appears.

On Windows use `Win`+`Shift`+`S`, on macOS `Cmd`+`Shift`+`4`, on Linux GNOME `PrtSc`.
